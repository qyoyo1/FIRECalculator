# FIRE Calculator Web

Web version of the FIRE calculator with the same logic as the iOS app:

- Asset inputs: cash, equity, real estate, pension
- Per-asset currency: USD, CHF, EUR, RMB
- Fixed scenario growth assumptions (Conservative/Base/Aggressive)
- Fixed FX conversion to USD
- FIRE outputs in USD:
  - Total projected assets at FIRE age
  - Annual income using 3% withdrawal
  - Monthly income (annual / 12)

## Run

No build step is required.

1. Open `index.html` directly in a browser, or
2. Serve the folder with any static server.
